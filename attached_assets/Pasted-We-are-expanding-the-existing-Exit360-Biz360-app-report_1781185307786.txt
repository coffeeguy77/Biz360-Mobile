We are expanding the existing Exit360 / Biz360 app reporting system into a premium broker-style Information Memorandum report builder.

IMPORTANT:

* Do not hardcode Bean Culture data into the app.
* Do not use demo-only fake data except where existing seeded data is already in the project.
* Use the current database, auth, valuation, listing, 360 tour, equipment, lease, and buyer-access systems already in the app.
* Build reusable database-backed report sections that work for any business listing.
* All report fields must be editable by the seller/admin.
* Report content must be exportable to PDF, HTML, and CSV.
* Report content must be importable from CSV so a user can download a template, fill it manually or with AI, then upload it back into the app.
* The report must combine app-generated valuation figures with editable broker-style narrative content.
* The output should feel like a high-end broker Information Memorandum, not a plain accounting report.
* Keep the current dark premium mobile UI style.
* Maintain mobile-first design.
* Do not break existing 360 tours, valuation divisions, equipment, leases, listings, leads, or messaging.
* No hardcoded prices, venues, suburbs, business names, or report content.
* Use the current listing/business IDs and user ownership permissions.
* The same report engine must work for seller app view, buyer HTML view, and PDF export.

PROJECT GOAL

Create a full Reporting / Information Memorandum module for the app.

The new module must allow sellers to build an attractive, informative business valuation report using:

* Existing app valuation figures
* Xero/Square revenue data
* Division-level valuation data
* Equipment ledger totals
* Lease analysis results
* 360 tour scene/pin/audio data
* Listing details
* Seller-supplied editable fields
* CSV imported narrative fields
* Buyer access controls
* HTML and PDF export

The module should sit under the existing Valuation tab using the existing “Full Report” button.

When the user taps Full Report, open a new reporting hub.
