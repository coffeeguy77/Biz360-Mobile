Build a mobile-first iOS and Android application called Biz360.

Biz360 is a business-for-sale marketplace where private sellers and business brokers can create immersive 360-degree business tours with interactive pins, narrated explanations, financial details, buyer analytics, in-app messaging, click-to-call tracking, and advertising upgrades.

The app must support three user types:
1. Buyer
2. Private Seller
3. Broker / Multi-listing seller
4. Admin

Core positioning:
“See the business before you buy it.”

The hero feature is an interactive Business Tour 360. Sellers can create a guided walkthrough of their business using phone photos. The seller captures each space using a guided capture flow. Basic mode uses 4 directional photos: front, right, back, left. Better mode supports 8 directional photos. The app stitches or presents these as a panoramic walkthrough-style viewer. Each tour space can contain interactive pins.

Tech stack:
Use React Native with Expo and TypeScript.
Use Expo Router.
Use PostgreSQL database.
Use Supabase or equivalent for auth, database, storage, and real-time messaging.
Use cloud storage for photos, videos, audio, documents, and tour media.
Use a 360 image viewer built with Three.js or React Native compatible panoramic viewer.
Use push notifications for buyer/seller messages.
Use Stripe for web payments and subscription management.
Allow future support for Apple RoomPlan / ARKit on iOS for LiDAR-enabled room scanning.

Design style:

Use dark navy, white, soft grey, electric blue, and green trust accents.
The app should feel like a mix of real estate marketplace, business broker CRM, and immersive 360 tour platform.
