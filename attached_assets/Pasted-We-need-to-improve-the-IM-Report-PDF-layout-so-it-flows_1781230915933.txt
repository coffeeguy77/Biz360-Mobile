We need to improve the IM Report PDF layout so it flows like a professional broker Information Memorandum instead of creating one page per report section.

Current issue:
The generated PDF is 42 pages because each report section is rendered on its own page, even when the section only contains one paragraph and a few bullet points. This creates too much empty space and makes the report feel thin and repetitive.

Do not remove the 40 report sections from the app or database.
The app should still allow sellers to edit all 40 sections.
But the PDF export must intelligently group and condense sections into fewer designed pages.

Target:
The same 40 report sections should export as approximately 14–22 polished PDF pages, depending on available content, charts, images, tables and access mode.

IMPORTANT:

* Do not hardcode Bean Culture.
* Do not delete existing report sections.
* Do not break HTML report, app view, CSV import, valuation, equipment, lease, 360 tour or buyer access logic.
* This is a PDF layout and flow improvement.
* Keep all report content available, but render it more intelligently.
* Buyer PDF and seller PDF must both use the improved layout.
* Seller-only/private sections must still respect access rules.

PDF FLOW REQUIREMENTS

Stop rendering every report section as a full page.

Instead, create grouped report chapters.

Suggested PDF structure:

1. Cover Page
2. Important Notice / Disclaimer + Report Snapshot
3. Table of Contents
4. Executive Summary + Key Selling Points
5. Business Overview + Reason for Sale + Buyer Suitability
6. Valuation Snapshot
7. Valuation Methodology + Range Explanation + Business Health Score
8. Financial Performance + Verified Revenue Sources
9. Division Breakdown + Revenue Stream Breakdown
10. COGS Breakdown + Addbacks and Adjusted EBITDA
11. Plant and Equipment Summary
12. Lease and Premises Summary + Lease Risk and Valuation Impact
13. Location and Market Context + Canberra Location Context
14. 360° Business Walkthrough + Key Tour Highlights
15. Operations and Systems + Staff and Owner Involvement
16. Supplier Summary + Customer Base
17. Brand and Digital Assets + Reviews and Reputation
18. Growth Opportunities + SWOT Analysis
19. Risks and Mitigations
20. Sale Inclusions + Sale Exclusions + Stock and Working Capital
21. Training and Handover + Due Diligence Documents Available
22. Verified Information + Buyer Access and Confidentiality + Next Steps
23. Final Disclaimer / Contact / Call to Action

This does not mean every report must be exactly 23 pages.
If content is short, combine further.
If charts/tables/images are present, allow extra pages.
The PDF engine should adapt to content length.

LAYOUT RULES

Create a layout system with these block types:

1. Cover block
2. Chapter divider block
3. Metric card grid
4. Two-column text block
5. Section group block
6. Table block
7. Chart block
8. Callout block

Do not force page breaks after every section.

Only force page breaks for:

* Cover
* Table of contents
* Major chapter dividers, if enabled
* Large charts/tables that need space
* Final call-to-action/disclaimer page

CONTENT DENSITY RULES

For short sections:
If a section has fewer than 250 words and no chart/table/image, allow it to share a page with related sections.

For medium sections:
If a section has 250–600 words, allow it to share a page if space remains.

For long sections:
If a section has over 600 words, allow it to occupy its own page or continue naturally.

For bullet-heavy sections:
Render bullets in compact two-column layout where appropriate.

For repeated short sections:
Group them under one larger chapter heading.

Example:
Instead of:
Page 3 Executive Summary
Page 4 Business Overview
Page 5 Key Selling Points
Page 6 Reason for Sale

Render:
Page 4: Executive Summary

* Left column: Executive Summary paragraph
* Right column: Key Selling Points cards/bullets
* Bottom row: Reason for Sale short note or Buyer Opportunity note

PAGE FILLING LOGIC

PDF renderer should use natural content flow.

Avoid leaving large blank areas at the bottom of pages.

If there is room after a short section, render the next related section on the same page.

Use CSS print rules:

* Avoid page-break-after on every section.
* Use page-break-inside: avoid for cards/tables where possible.
* Use page-break-before only for cover, TOC and major chapters.
* Allow paragraphs and normal section groups to flow.
* Use widows/orphans control if available.
