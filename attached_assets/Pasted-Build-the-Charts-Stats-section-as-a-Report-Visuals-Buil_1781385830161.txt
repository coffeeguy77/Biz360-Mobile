Build the Charts & Stats section as a Report Visuals Builder.

Current issue:
The app has a “Charts & Stats” entry in the IM Report area, but it is not built yet. We need this to become a flexible builder where sellers/admins can create real report visuals and attach them to specific report sections.

CRITICAL:
Do not use fake/demo chart data.
Every chart, stat, graph, table or visual must come from real app data or seller-entered manual data.
If data is missing, show “Data not available” and do not render fake visuals.

GOAL:
Create a visual builder that lets the seller choose:
1. Which report section the visual belongs to
2. What type of visual to create
3. What real data source to use
4. How it should be displayed
5. Whether it appears in PDF, HTML, buyer report and seller report

DATABASE

Create a report_visuals table.

Fields:
- id
- user_id
- listing_id
- section_key
- title
- subtitle
- visual_type
- data_source_type
- data_source_config JSON
- visual_config JSON
- manual_data JSON
- chart_data JSON
- sort_order
- include_in_pdf boolean
- include_in_html boolean
- include_in_buyer_report boolean
- include_in_seller_report boolean
- visibility: public / approved_buyers / seller_only / hidden
- source_label
- source_confidence: high / medium / low / manual / unavailable
- status: ready / needs_data / needs_review / hidden
- created_at
- updated_at
- deleted_at

VISUAL TYPES

Support these visual types for v1:

1. stat_card
Single large metric.

2. metric_grid
Multiple stat cards in one block.

3. table
Clean comparison table.

4. bar_chart
Vertical bar chart.

5. horizontal_bar_chart
Best for division revenue, equipment values, top assets.

6. donut_chart
Only for real part-of-total data.

7. valuation_bridge
Adjusted EBITDA × multiple + equipment = estimated value.

8. funnel
Views → tour starts → enquiries → document requests → inspections.

9. checklist
Due diligence or verification checklist.

10. score_card
Business health, lease risk, confidence score.

11. risk_matrix
Risk level vs mitigation.

12. location_snapshot
Location/travel/catchment stats and notes.

CHART RULES

Do not render charts unless the selected data source has real data.

Examples:
- Revenue by Division requires real division revenue.
- Valuation by Division requires real division valuation values.
- Equipment Category chart requires real equipment categories and values.
- Lease Risk chart requires real lease analysis.
- Business Health breakdown requires real category-level scores.
- Buyer Funnel requires real engagement stats.
- Donut charts require data that adds up to a meaningful total.

If data is missing:
- status = needs_data
- show “Data not available”
- do not render fake visual.

REPORT INTEGRATION

PDF exporter:
- render report_visuals attached to each section_key
- respect include_in_pdf
- respect buyer/seller visibility
- use static chart rendering or simple SVG/CSS charts
- skip unavailable visuals

HTML report:
- render report_visuals attached to each section_key
- respect include_in_html
- use interactive/responsive charts where possible
- skip unavailable visuals or show seller-only “needs data” warnings

App preview:
- render report visuals inside the app preview

ACCESS CONTROL

Only listing owner/admin can create/edit/delete report visuals.

Buyer can only see visuals where:
- include_in_buyer_report = true
- visibility allows buyer access
- data source does not expose seller-only data

- visuals ready

- manual visuals
- verified visuals
- seller-only visuals
